## 무엇을 해 봤나

| 순서 | 시도 | 결과 | 배운 점 |
|---|---|---|---|
| 1 | 코드로 그린 SVG 꽃 | 탈락 ("실제 꽃으로 보여야 해") | 예쁨은 기능 요구사항이다. 구현 전에 시안으로 확인하길 잘했다 |
| 2 | 배경 지운 꽃 사진 합성 (canvas) | SVG보다 낫지만 사진 같지 않음 | 그림자·빛·포장지 주름이 없으면 "붙인 티"가 난다 |
| 3 | 합성 → Gemini 이미지 편집 (수동) | 만족 | 합성은 최종 결과가 아니라 AI에게 주는 **설계도**로 쓰면 된다 |
| 4 | Qwen-Image-Edit-2511 (HF Space) | 품질 좋음, 장미 10송이 → 9/8/9 | 무료 Space는 게스트 GPU 한도가 있어서 몇 번밖에 못 돌린다 |
| 5 | SDXL + ControlNet (Colab T4) | 송이 수는 지키지만 그림 그대로 | 구조를 강하게 묶으면 사진처럼 바꾸는 힘도 같이 약해진다 |
| 6 | **Qwen-Image-Edit-2511 (데스크톱 3060 Ti)** | **9장 모두 송이 수 일치, 장당 약 57초** | 8GB GPU도 양자화(GGUF Q4)와 4단계 LoRA면 충분하다 |

남은 문제는 AI보다 **재료**에 있었다. "분홍 장미" 재료가 연핑크인지 진핑크인지 애매하면 AI도 헷갈린다. 주황빛이 도는 "노란 튤립"도 그랬다.

## 학습 노트

### 이미지 편집 AI 용어

| 용어 | 뜻 |
|---|---|
| img2img / 이미지 편집 | 입력 이미지를 바탕으로 새 이미지를 만든다. 텍스트로 "사진처럼 바꿔"라고 지시할 수 있다 |
| ControlNet | 윤곽선 같은 구조를 강제로 따르게 하는 보조 모델 |
| LoRA | 큰 모델에 붙이는 작은 추가 가중치. 여기서는 50단계 → 4단계로 줄여 주는 "Lightning" LoRA를 썼다 |
| 양자화 (GGUF Q4) | 가중치를 4비트로 줄여 VRAM과 용량을 아낀다. 품질이 조금 떨어지는 대신 8GB GPU에 들어간다 |
| seed | 무작위 값의 시작점. 같은 seed면 같은 결과가 나와야 하지만, GPU·라이브러리 버전이 바뀌면 달라질 수 있다 |

### ComfyUI를 코드로 부르기
ComfyUI는 노드를 이어 붙이는 GUI지만, 같은 그래프를 JSON으로 HTTP API에 보낼 수 있다.

1. `POST /upload/image`: 밑그림 업로드
2. `POST /prompt`: 노드 그래프(JSON) 실행 요청 → `prompt_id`
3. `GET /history/{prompt_id}`: 끝났는지 확인 (폴링)
4. `GET /view?filename=…`: 결과 PNG 받기

Phase 6의 AI 워커가 할 일이 바로 이것이다.

### Windows 데스크톱을 맥에서 SSH로 다루기
- Windows에도 OpenSSH Server가 있다. 관리자 계정의 공개키는 `C:\ProgramData\ssh\administrators_authorized_keys`에 두고, 이 파일 권한을 Administrators와 SYSTEM만으로 제한해야 키 로그인이 된다.
- 키 등록 뒤 `PasswordAuthentication no`와 `KbdInteractiveAuthentication no`로 비밀번호 로그인을 막았다. 하나만 끄면 다른 방식으로 비밀번호를 계속 물어본다.
- ComfyUI는 `127.0.0.1`에만 열고, 맥에서는 SSH 포트 포워딩(`ssh -L 8188:127.0.0.1:8188`)으로 접속했다. 서비스를 외부에 열지 않아도 된다.
- SSH 세션이 끝나면 그 안에서 띄운 프로그램도 같이 꺼진다. 오래 도는 프로그램은 작업 스케줄러에 등록해 사용자 세션에서 실행했다.
- PowerShell에서 종류가 다른 결과를 한꺼번에 출력하면 일부가 생략된다. `Format-Table`을 쓰고 한 번에 하나씩 확인했다.

### 막혔던 것
- Colab 무료 RAM(약 12.7GB)에서 `enable_model_cpu_offload()`를 쓰니 RAM이 부족해 커널이 재시작됐다. VRAM이 충분했으니 처음부터 `pipe.to("cuda")`로 GPU에 올렸어야 했다.
- 공식 Qwen Space는 GPU 360초를 요청해서 게스트 한도를 넘었다. 4단계 버전 Space는 요청 시간이 짧아서 돌아갔다.
